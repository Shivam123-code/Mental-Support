# KleverKlues™

**"You're Not Alone."**

The World's Most Trusted Human Wellbeing & Emotional Support Ecosystem.

## About

KleverKlues is a Human Wellbeing Infrastructure Platform — a connected ecosystem where people can heal emotionally, grow mentally, connect safely, contribute meaningfully, learn continuously, support humanity, and build emotionally resilient lives.

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Images:** Unsplash (via next/image remote patterns)

## Pages

1. **Home** — Hero, categories, how it works, programs, community, trust, enterprise, testimonials
2. **Get Support** — Emotional Health, Relationships, Career, Children, Special Support, Personal Growth
3. **Assessments** — Emotional Wellness, Personality, Career, Relationship, Workplace assessments
4. **Programs** — Guided wellbeing journeys (Emotional Recovery, Relationships, Student, Workplace, Lifestyle)
5. **Professionals** — Verified counsellors, psychologists, coaches, mentors
6. **Community** — Support circles, peer groups, Human Impact Score
7. **Enterprise** — Corporate wellness, EAP, burnout analytics, dashboards
8. **Academy** — Professional certifications, parenting, student skills, corporate training
9. **Resources** — Articles, videos, podcasts, meditation, sleep audio, brain music
10. **SOS** — 24/7 crisis support, helplines, safety infrastructure
11. **About** — Brand story, mission, vision, values, roadmap

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
